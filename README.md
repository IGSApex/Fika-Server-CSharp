# Fika Server

Fika multiplayer server component with squad management.

## Features

- **Squad creation:** Players can create squads from the Fika client.
- **Invitations:** Invite players to a squad and accept or decline invitations.
- **Squad membership:** Track squad leaders, members, and squad IDs.
- **Squad management:** Handle leaving squads and leader-managed membership.
- **Five-player squads:** Support groups of up to five players.
- **Client updates:** Send squad notifications and membership changes to connected clients.

## How It Works

Players create and manage squads through the Fika client. The server processes invitations and membership changes and shares the updated squad information with the players.
